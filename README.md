# OrbitTube

Watch YouTube videos in sync with friends in real time.

🔗 https://orbittube-production.up.railway.app

## Tech Stack
- Node.js + Express
- Socket.io
- YouTube IFrame API
- Vanilla JS, HTML, CSS

## Run Locally
1. Clone the repo
2. `npm install`
3. `node server.js`
4. Open `http://localhost:3000`
